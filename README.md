# Parfum Shop

Ein Full-Stack Parfum-Shop mit React Frontend und Node.js/Express Backend.

## Projektstruktur

```
parfum-shop/
├── client/          ← React Frontend (Vite)
├── server/          ← Node.js + Express Backend
├── .gitignore
└── README.md
```

## Getting Started

### Voraussetzungen

- Node.js (v18+)
- npm

### Client starten

```bash
cd client
npm install
npm run dev
```

### Server starten

```bash
cd server
npm install
npm run dev
```
